# ROS v1 Scope

## In scope now

Project isolation, TypeScript server shell, SQLite migrations, health endpoint, SSE heartbeat, empty UI entry shells, architectural documents, and a health test.

## Interfaces reserved for v1

Catalog publishing, event allocation, omnichannel orders, kitchen status, payments, inventory movements, costs, audit logs, and asynchronous reporting sync.

## Explicitly out of scope now

Real products or orders, payment providers, printer integration, LINE webhook integration, n8n workflow changes, Google Sheets writes, receipt image recognition, legacy migration execution, VPS provisioning, and changes to POS/KDS/customer production pages.
