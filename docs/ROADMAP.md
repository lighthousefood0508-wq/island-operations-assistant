# Roadmap

1. Phase 0.5: Constitution v2 alignment, contracts, and guard tests - complete after verification.
2. Phase 1: Architecture Owner-approved Catalog Admin and Product Contract publication.
3. Phase 2: events, availability allocation, Customer preorder.
4. Phase 3: POS and Kitchen pilot from the same REST/SSE source.
5. Phase 4: Cost ledger and daily Sales Contract import, then Google Sheets reporting export.
6. Phase 5: LINE and receipt review through controlled adapters.
7. Phase 6: VPS production deployment, backup restore test, monitoring, and operational handover.

Each phase requires its own acceptance test and rollback plan before advancing.
