# ROS v1 Scope

## In scope now

Project isolation, TypeScript server shell, strict SQLite table boundaries, Product/Sales Contract definitions, architecture guards, health endpoint, SSE heartbeat, empty UI entry shells, documents, and foundation tests.

## Interfaces reserved for v1

Catalog publishing, event allocation, omnichannel orders, kitchen status, payments, Cost-owned BOM/inventory movements, audit logs, daily Sales Contract import, and asynchronous reporting export.

## Explicitly out of scope now

Real products or orders, payment providers, printer integration, LINE webhook integration, n8n workflow changes, Google Sheets writes, receipt image recognition, legacy migration execution, VPS provisioning, and changes to legacy POS/KDS/customer pages.
