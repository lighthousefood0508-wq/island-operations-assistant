# Logs

This folder holds generated output from approved ROS and engineering scripts.

Allowed:

- Startup, shutdown, diagnostics, health, and tunnel logs
- Timestamped operational output useful for troubleshooting

Do not place:

- Source code, scripts, credentials, SQLite databases, or manual backups

All generated log files are ignored by Git. Keep secrets out of logs; this README is the only tracked file in this folder.
