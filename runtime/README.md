# Runtime

This folder holds transient files produced while ROS or an approved engineering script is running.

Allowed:

- Current external-link text files
- PID, lock, health, and temporary status files
- Tunnel runtime output that is needed only for the active process

Do not place:

- Source code, executable scripts, documentation, credentials, backups, or long-term logs

Everything in this folder is ignored by Git except this README. Runtime files may be deleted or regenerated by the owning process.
